Open Widget quickstart ↗
AccountFunding.tsx
import { LayerswapWidget } from '@layerswap/widget-react';

const config = {
  apiKey: 'YOUR_API_KEY',
  version: 'mainnet',
  initialValues: {
    to: 'BASE_MAINNET',
    toAsset: 'USDC',
    lockTo: true,
    lockToAsset: true,
  },
} as const;

export function AccountFunding() {
  return <LayerswapWidget config={config} />;
}
layerswap.js
import { mountWidget } from '@layerswap/widget-js';

const handle = await mountWidget(
  document.getElementById('layerswap'),
  {
    config: {
      apiKey: 'YOUR_API_KEY',
      version: 'mainnet',
    },
  },
);

// When your view is torn down:
handle.destroy();

03

How a swap works

One flow, clear ownership.

  1. Your app or Widget Quote Price a supported route and amount.
  2. Your app or Widget Create swap Set the route, recipient, and correlation data.
  3. User Fund Follow the returned funding instructions.
  4. Layerswap Execute Coordinate the supported route and payout.
  5. Destination Receive Funds arrive at the requested address or account.

Layerswap coordinates supported chains, assets, wallets, exchanges, funding methods, and destination transfers behind this flow.

04

Shape the experience

Fix what matters.
Leave the rest flexible.

Widget controls vary by component. The dedicated Deposit Widget is the verified choice when your app must fix the receiving address.

Your application can

  • 01Fix the destination network and address with the Deposit Widget
  • 02Choose accepted destination tokens with the Deposit Widget
  • 03Prefill or lock route fields in the Full Widget
  • 04Configure theme, wallet providers, and loading behavior
  • 05React to creation, status, completion, and error callbacks

The user can

  • 01Choose a source network and token when those fields are not locked
  • 02Choose a wallet or account
  • 03Choose an available funding method in the Deposit Widget
  • 04Enter an amount within the route limits
  • 05Review the quote before funding
