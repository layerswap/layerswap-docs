---
title: "Partial integration"
description: "Reuse an existing EVM wagmi config with the self-bundled Widget."
---

<Warning>
  This is the self-bundled path. With the recommended React loader, pass [`wagmiConfig`](/widget/wagmi-config) directly.
</Warning>

Use partial integration when your app already owns wagmi and you want the self-bundled Widget to share its EVM account and connectors while Layerswap supplies route settings.

```tsx
import { LayerswapProvider, Swap, WidgetLoading, useSettings } from '@layerswap/widget';
import { createEVMProvider } from '@layerswap/wallet-evm';
import { wagmiConfig } from './wagmi';

function ReadyWidget() {
  const walletProviders = [createEVMProvider({ wagmiConfig })];

  return (
    <LayerswapProvider
      config={{ apiKey: 'YOUR_API_KEY' }}
      walletProviders={walletProviders}
    >
      <Swap />
    </LayerswapProvider>
  );
}

export function Widget() {
  const { settings, loading } = useSettings({ apiKey: 'YOUR_API_KEY' });
  if (loading || !settings) return <WidgetLoading />;
  return <ReadyWidget />;
}
```

Your host wagmi config must include every EVM chain and transport the Widget should use. Keep the config and provider array stable, and place the Widget under the same host `WagmiProvider` and query client.

For non-EVM providers, add the corresponding native packages to the array. See [Wallet providers](/widget/advanced/wallet-providers).
