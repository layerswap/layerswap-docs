## Include useful context

Share enough information to reproduce the issue without exposing secrets:

- Integration surface and package version
- Mainnet or testnet environment
- Swap ID and relevant transaction hash
- API endpoint, HTTP status, and error code or empty-body response
- Canonical source/destination network and token identifiers
- Browser/framework version for Widget or Hosted Page issues
- `ManifestError.reason`, CSP header, and Widget console provenance line for loader failures

Never share API keys, webhook secrets, wallet private keys, seed phrases, authorization signatures, or unredacted sensitive user data.
